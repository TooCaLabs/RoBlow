# Quick-mode

On New UI, flip **Quick-mode** on. `;` opens the overlay. `esc` closes it. `q` turns Quick-mode off.

Binds do not fire while you are typing in a field.

## Default binds

| Key | Command |
| --- | --- |
| `;` | Open the overlay |
| `h` | home |
| `d` | discover |
| `c` | charts |
| `s` | search |
| `a` | avatar |
| `i` | inventory |
| `f` | friends |
| `m` | messages |
| `u` | groups |
| `p` | profile |
| `b` | catalog |
| `e` | creator |
| `,` | settings |
| `v` | premium |
| `q` | Leave Quick-mode |

## Commands

| Command | What it does |
| --- | --- |
| `help` | List commands |
| `menu` | Site map |
| `home` | Home |
| `discover` | Discover |
| `charts` | Charts |
| `search [query]` | Search |
| `avatar` | Avatar Editor |
| `inventory` | Inventory |
| `friends` | Friends |
| `messages` | Messages |
| `groups` | Communities |
| `profile` | Your profile |
| `catalog` | Catalog |
| `creator` | Creator dashboard |
| `settings` | Roblox settings |
| `premium` | Premium |
| `go <path>` | Open a roblox.com path (or a full URL) |
| `play <place\|name>` | Launch a place ID or search and play the first hit |
| `install [query]` | Chrome Web Store wrapper (`install mods` works too) |
| `quick` | Turn Quick-mode off |
| `bind` | Show binds |
| `bind <key> <command>` | Set a bind |
| `bind open <key>` | Change the overlay key |
| `unbind <key>` | Remove a bind |
| `binds` | List binds |
| `open [key]` | Show or set the overlay key |
| `clear` | Clear the overlay |
| `close` | Close the overlay |

Aliases: `inbox` → messages, `communities` → groups, `shop` → catalog, `create` → creator, `account` → settings. `q` / `quit` / `exit` close the overlay.

## Examples

```
play 1818
play adopt me
go /games
go https://create.roblox.com
install btroblox
bind g groups
bind open `
unbind g
```

After `bind`, press `esc`, then the key on the page (not inside the overlay).
