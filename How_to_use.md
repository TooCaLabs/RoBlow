# How to use RoBlow

Install Roblox in `/Applications`, then open `RoBlow.app` from [Releases](https://github.com/TooCaLabs/RoBlow/releases).

## Home

The home board is a grid of widgets. Hit edit to move, resize, add, or remove them. Done saves the layout.

## Accounts

Sign in from Home or an instance. Login is a Roblox page inside RoBlow. Your cookie stays on this Mac.

Pick which account an instance uses before you launch.

## Instances

Sidebar → **+** makes a new instance. Click one to rename it, assign an account, and launch.

- **Launch** — opens New UI for that instance
- **Bring to Front** — focuses a running player
- **Terminate** — quits that player

`⌘N` also creates an instance.

## New UI

This is roblox.com inside RoBlow. Browse and hit Play — the official Roblox player starts, not a second copy of the site.

Each instance can have its own New UI tab.

## Quick-mode

On New UI, turn on **Quick-mode**. `;` opens the overlay.

Useful commands: `help`, `home`, `discover`, `search`, `play <place|name>`, `install`, `bind`, `quick`.

Default letter binds jump around the site (home, discover, catalog, and so on). They do not fire while you are typing in a field.

## Mods

**Mods** in the sidebar is FastFlags and client settings. They write into `~/Library/Application Support/Roblox/`, not into `Roblox.app`.

## Web mods

On an instance (or Mods), use **Install mods**. That opens the Chrome Web Store wrapper.

Installed extensions live in `~/Library/Application Support/RoBlow/Extensions/`. Enable them per instance. They apply to New UI for that instance. After install or toggle, New UI reloads.
