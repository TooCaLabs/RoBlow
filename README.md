# RoBlow

A launcher for Roblox for macOS, and I hate Swift now.

RoBlow launches the official Roblox player, keeps multiple instances, and puts roblox.com in its own browser (New UI).

## Install

1. Install [Roblox](https://www.roblox.com/download) to `/Applications/Roblox.app`
2. Grab `RoBlow.app` from [Releases](https://github.com/TooCaLabs/RoBlow/releases)
3. Move it somewhere like `/Applications` and open it

### Requires: macOS 15 or later.

## Features

- Home board with editable widgets
- Multiple named instances
- Account sign-in (cookies stay on your Mac)
- New UI — roblox.com inside RoBlow
- Quick-mode keyboard overlay
- Mods and FastFlags
- Chrome Web Store extensions for New UI
- An entirely Local Roblox launcher
